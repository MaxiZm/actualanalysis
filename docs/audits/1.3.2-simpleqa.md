# SimpleQA Verified metric check

For the current input, the count likelihood is not an F1 error. All 69 SimpleQA observations in the corrected input are from Epoch; the accepted 1.3.1 fit used 44 Epoch observations. No Kaggle F1 rows entered that fit.

Epoch explicitly reports the fraction of the 1,000 questions answered correctly, counting abstentions as unsuccessful answers. Its methodology expressly distinguishes this accuracy metric from Google's F1. The published implementation uses `accuracy()` and `stderr()`, with correct=1, incorrect/not-attempted=0. GPT-5.5's original CSV row reports mean_score=.63 and stderr=.0152752523. The site's August 27, 2026 change added an anti-abstention instruction and retired earlier prompt scores; future metadata should pin that protocol.

Sources: [Epoch methodology](https://epoch.ai/benchmarks/simple-qa-verified), [Epoch's published scorer](https://gist.github.com/tadamcz/27b929c0923a4c539b0655536cd220ea), [Epoch original runs](https://epoch.ai/data/benchmarks.csv).

Google's paper uses a different headline metric: the harmonic mean of C/N and C/A, where C is correct answers, N all questions and A attempted questions. Therefore F1=2C/(N+A), which cannot be interpreted as C/N or multiplied by 1,000 to invent successes. Source: [Google DeepMind/Research paper, Section3 and Table7](https://arxiv.org/html/2509.07968).
