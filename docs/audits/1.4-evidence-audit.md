# GPT-5.6 Sol versus GPT-5.5 evidence audit

Audited on 2026-09-05 against the accepted 1.3.2 publication. The unit of evidence is one source observation of one exact model, benchmark revision and evaluation configuration. The replay baseline is `work/review-140/merged-records.json` (4,222 raw records); the accepted posterior is in `work/pipeline/2026-09-04T21-44-30.598Z`.

The Chat reversal was not a well-supported finding that GPT-5.5 is better. It combined a verified effort-classification error, missing direct Arena evidence, and weakly identified domain estimates. These are general data/model issues; no correction uses model age or the desired ranking as evidence.

## Accepted 1.3.2 comparison

Paired probabilities below are recalculated from the same 8,000 posterior draws, rather than approximated from independently displayed intervals.

| Profile | Sol median | GPT-5.5 median | P(Sol higher) | 90% interval of Sol minus GPT-5.5 |
|---|---:|---:|---:|---:|
| Mixed | 65.42 | 64.92 | 53.0% | −10.73 to +10.14 |
| Agentic | 65.12 | 61.18 | 81.3% | −4.15 to +11.33 |
| Chat | 63.39 | 65.53 | 40.5% | −21.42 to +13.23 |

The Chat comparison is unresolved under the old model. Its median difference should not be presented as established superiority.

## 1. Variable reasoning efforts were pooled as a fixed system

**High severity; directly verified.** Sol, Terra and Luna lacked `default_effort_tier`, `max_effort_tier`, `effort_tier_order` and reasoning metadata. The old `isFixedEffort` implementation therefore put all their results into one system, irrespective of the effort named by the evaluator. GPT-5.5 already had two declared endpoints and was treated differently.

For Sol, the five independent ARC-AGI-2 rows from Low through Max were 42.50%, 67.08%, 85.42%, 90.00% and 92.50%. The accepted preparation assigned all five to `gpt-5.6-sol@max-common`. The official result page explicitly separates the five variants. GPT-5.5 has 33.33%, 70.42%, 83.33% and 85.00% for Low through XHigh. Sol therefore does not win at every matched setting: the Medium ARC result favors GPT-5.5. [ARC Prize Sol results](https://arcprize.org/results/openai-gpt-5-6-sol), [ARC Prize source dataset](https://arcprize.org/media/data/leaderboard/v2.json).

Production metadata now records medium/default and max/maximum for Sol, Terra and Luna, with the documented order none, low, medium, high, xhigh, max. Ultra describes multi-agent orchestration and is not added as a single-model effort. Sources: [Sol API model](https://developers.openai.com/api/docs/models/gpt-5.6-sol), [Terra API model](https://developers.openai.com/api/docs/models/gpt-5.6-terra), [Luna API model](https://developers.openai.com/api/docs/models/gpt-5.6-luna), [GPT-5.6 release](https://openai.com/index/gpt-5-6/).

Astra has the same missing-metadata problem. Its official page documents low, medium, high, xhigh and max, but the reviewed model page and guide do not name a default. Its maximum, order, reasoning control and first-party references are now recorded; its default remains unspecified. An unknown default must not turn a documented variable-effort model into a fixed-effort system. [Astra API model](https://developers.openai.com/api/docs/models/gpt-6-astra), [Astra guide](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra).

## 2. Direct Arena evidence was lost during model alias resolution

**High severity; directly verified.** The raw baseline already contained `gpt-5.6-sol-xhigh`, but the registry did not recognize that exact source label. It also missed `gpt-5.6-terra-xhigh`, `gpt-5.6-luna-xhigh` and `gpt-5.5-high`. All four were present in `data/manual/unmapped.yaml` and excluded from the fit. Bare GPT-5.5 was recognized.

The source's September 1 style-controlled overall snapshot was retrieved again on September 5; the five values, variances and counts exactly match the saved observations. No freshness update is required to recover them.

| gpt-5.5-high | 1482.33430 | 1.96743 | 63,265 |
| gpt-5.5 | 1477.23523 | 1.95888 | 64,686 |
| gpt-5.6-terra-xhigh | 1466.23310 | 2.58283 | 23,942 |
| gpt-5.6-luna-xhigh | 1452.36358 | 2.56615 | 24,433 |

Sol's 0.53-rating-point advantage over the named GPT-5.5 High entry is small relative to the source uncertainty, and the efforts differ. It is useful direct communication evidence, not a reason to force a large Chat gap. Source: [Arena's native dataset](https://huggingface.co/datasets/lmarena-ai/leaderboard-dataset/viewer/text_style_control/latest).

The four exact aliases are now registered. A source-scoped rule preserves their explicitly named effort, checking that the suffix is in the resolved model's documented effort order. It does not infer the effort of bare GPT-5.5, unsupported labels or other sources.

There was also a configuration identity hazard: alias resolution deduplicates immediately by canonical model, benchmark, source and configuration. Bare GPT-5.5 and GPT-5.5 High both had empty configurations, so adding only an alias could discard one before annotation. The source effort is now materialized in `config.reasoning_effort` before deduplication. Existing explicit metadata is preserved. Both configurations survive replay, and all 4,222 raw observations remain present.

## 3. Extrapolated communication drives the old Chat reversal

**High analytical risk; quantified from the accepted posterior.** Sol's median domain estimate exceeds GPT-5.5 in reasoning (65.07 versus 62.65), knowledge (64.75 versus 62.54), and agentic work (64.81 versus 58.14). It falls behind in code (56.82 versus 59.82) and communication (54.99 versus 60.55), both flagged as extrapolated for these systems.

The communication 90% intervals are 36.32–71.04 for Sol and 38.71–83.40 for GPT-5.5. The fit had no Sol Arena cell. Its one communication-loading cell came from cross-loadings in other evidence, which is not equivalent to a directly measured preference result. GPT-5.5 had Arena evidence only in its standard system, with the maximum communication trait extrapolated through the effort model. The resulting median can reverse the profile ordering even when better measured domains favor Sol.

Correct the verified evidence errors first, then evaluate alternative pooling and profile models on held-out observations, calibrated uncertainty, and stability to removing entire benchmark families. The target should be predictive validity across models, not making this pair sort a particular way.

## Same-revision cross-checks and limits

Original Epoch FrontierMath v2 observations favor Sol at the highest declared single-model efforts: Tiers 1–3 are 89.1228% versus 85.2632%, and Tier 4 is 82.9268% versus 72.5000%. The source includes run-level standard errors; those should remain authoritative. The July OpenAI comparison is consistent after display rounding. MRCR 512K–1M slightly favors GPT-5.5, 74.0% versus 73.8%, so a universal superiority constraint is not supported. [Epoch original runs](https://epoch.ai/data/benchmarks.csv), [OpenAI's July comparison](https://openai.com/index/gpt-5-6/).

MathArena is a rolling fitted composite. Its current values have moved from the saved September 4 values: Sol 61.6% to 64.3%, GPT-5.5 60.6% to 61.0%. These are temporal differences, not proven transcription errors. The audit leaves the historical snapshot unchanged so the data-only and mathematical-model comparisons use a controlled evidence set. Any refresh should capture the entire composite snapshot consistently. [MathArena models](https://matharena.ai/models).
